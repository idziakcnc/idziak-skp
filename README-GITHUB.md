# IDZIAK.COM.PL – pliki do GitHub Pages

## Najprostsza podmiana
1. Otwórz repozytorium strony w GitHub.
2. Kliknij **Add file → Upload files**.
3. Przeciągnij całą zawartość tego folderu, także folder `assets`.
4. Zaznacz **Commit directly to the main branch** i kliknij **Commit changes**.
5. Nie usuwaj pliku `CNAME` – utrzymuje domenę `idziak.com.pl`.

## Zawartość
- `index.html` – strona główna
- `styles.css` – wygląd i wersja mobilna
- `script.js` – menu, udostępnianie i galeria
- `assets/` – zoptymalizowane zdjęcia i logo
- `robots.txt`, `sitemap.xml`, `llms.txt` – SEO i wyszukiwarki AI
- `manifest.webmanifest` – instalacja strony na telefonie
- `404.html` – strona błędu
